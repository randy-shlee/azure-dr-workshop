# 00. 시작하기

[목차](README.md) · [다음: 배포](01-deploy.md)

## 목표

새로 배포할지 준비된 환경을 관찰할지 정하고, 비용과 변경 권한을 확인합니다.
[아키텍처 개요](../workshop/architecture.md)를 함께 봅니다.

## 할 일

1. 강사가 지정한 Azure 테스트 구독으로 로그인합니다.
2. **prefix, 실제 브라우저 공인 IPv4 CIDR, 종료일, 단일 오퍼레이터, 정리 담당자**를 적습니다.
   새 prefix는 소문자로 시작하는 3~12자 소문자/숫자입니다.
3. full의 AKS 4노드·PG 2서버·EH/Redis/Search 양 리전 비용을 승인받습니다.
   알려진 소계 약 USD 1,615.41/월은 상한이 아니며 환경을 추가하면 별도 과금합니다.
4. 배포 중만 사용하는 승인 CIDR+mTLS Docker 2376과 종료 후 정리에 동의했는지 확인합니다.
   cloud Automation/public PaaS를 여는 과정이 아닙니다.
5. DR는 **배포와 별도 승인**입니다. EH는 이전 primary로 failback하지 못한다는 점과
   원래 이벤트 보존/replay 계획을 확인합니다.

기본 과정은 검증된 **full**입니다. lite를 별도 선택하면 EH/Redis/Search와 해당 검증이
제외되며 full 성공으로 기록하지 않습니다. 임의로 SKU/리전/기능을 바꾸지 않습니다.
기존 환경 전체 템플릿 덮어쓰기는 지원 경로가 아닙니다.

## 안 되면 멈추기

구독·CIDR·비용·변경 담당자가 불명확하면 배포/전환하지 않습니다.
권한이나 용량 문제를 public access/상위 SKU/다른 리전으로 임의 우회하지 않습니다.
