# v1.0.7 로컬 배포본 기록

기록일: 2026-10-28 UTC. **로컬 전용이며 공개 게시하지 않았습니다.**
이 문서는 과거 자산의 식별과 검증 범위만 보존합니다. 현재 소스나 포털 배포의 성공을 의미하지 않습니다.
이 이미지에는 최신 보안 수정이 없으므로 [보안 안내](../../SECURITY.md)에 따라 새 릴리스를 생성해야 합니다.

## 상태

- 기존 환경: 패키지에서 추출한 수정 없는 도구로 양 앱 업데이트 성공.
- 브라우저 업로드 버튼: 정확히 **2,008객체 / 10,000,000,000 bytes** 완료.
- 중부·남부 앱에서 primary/secondary inventory, 실제 읽기와 복제 fence 검증 성공.
- 신규 환경: 동일 패키지의 인프라/앱/자동 샘플/최종 smoke 전체 배포 **Complete**.
  실행 중 패키지 수정이나 숨은 수동 복구 없이 단일 명령으로 완료했습니다.

기본 샘플은 1 GiB 7개, 386,655,232 bytes 1개, 1 MiB 2,000개입니다.
10 GB 전체를 메모리/임시 파일로 만들지 않으며 앱의 staged block은 최대 4 MiB입니다.
상한은 서버 고정이며 요청의 크기/대상 변경을 허용하지 않습니다.

## 당시 확인한 범위

양 앱에서 primary/secondary의 2,008개·정확히 10 GB inventory, 실제 1 MiB 읽기,
최종 manifest 종료 시각 이후 Last Sync Time을 확인했습니다.
동시 업로드는 HTTP 409, 임의 크기 입력은 HTTP 400, 다른 Origin의 업로드 시작은 HTTP 403이었습니다.

양 앱에서 Blob/PG/Redis 실제 쓰기 후 동일 레코드 읽기, Search의 정확한 문서 조회,
Event Hubs의 실제 이벤트 본문 소비까지 통과했습니다. 단순 DNS/TCP 성공만 검사하지 않았습니다.
기존 `sampledata`의 과거 10 GiB 예산 데이터는 삭제하거나 새 상한 성공 증거로 바꾸지 않았습니다.

실제 환경의 주소·실행 UUID·분 단위 로그와 개발 중 오류 기록은 공개 안내에서 제외했습니다.
이전 `v1.0.6-rc.1`과 `v1.0.6`은 사용하지 않습니다.

## 새 환경 자동 재현과 보관

새 prefix로 추출한 `v1.0.7`의 `deploy-local-package.ps1`을
`-ConfirmCreate`, 승인 CIDR, 보호된 SecureString 암호로 실행했습니다.
`-SkipSampleData`나 기존 인프라 config를 사용하지 않았습니다.
자동 배포 상태는 **Complete**였으며 한 번의 관측상 전체 실행은 약 49분이었습니다.
소요 시간 보장값이 아닙니다.

| 검증 | 결과 |
|---|---|
| 인프라 생성부터 앱/샘플까지 | 수정 없는 추출 패키지 한 명령으로 완료 |
| 양 앱 | 정확한 archive-SHA 태그의 사설 ACR 이미지, Pod Ready |
| 자동 CLI 샘플 | 2,008개 / 정확히 10 GB, KRC/KRS 앱의 양 endpoint 실제 읽기와 fence 통과 |
| 5개 백엔드 | Blob/PG/Redis 정확한 readback, Search 정확한 문서, EH 본문 소비 성공 |
| Traffic Manager | 양 endpoint `Online` |
| 업로드 API 재개 | 자동 CLI가 만든 기존 2,008개 파일을 안전하게 인식하고 `completed` |
| 재개 후 최종 복제 | 양 앱 × 양 endpoint에서 동일한 최종 manifest/2,008개/10 GB/실제 읽기 확인, 새 fence 통과 |
| 임시 자원 | Docker Deployment/Service, 2376 NSG 규칙, 임시 AcrPush, 암호/인증서 디렉터리 제거 확인 |
| ACR | public Disabled / admin disabled 유지 |
| 실제 DR baseline | private RA-GRS/KRS secondary, PG Ready Primary/GeoAsyncReplica, EH 양방향 metadata pairing Succeeded 및 primary pending 0 |

해당 관측에서 알려진 비용 소계는
약 **USD 1,615.41/월**이며 가변 사용량/빌드 비용은 별도입니다.
`expiry` 태그는 자동 삭제가 아닙니다. 보관 종료는 소유자의 별도 결정입니다.

배포 방법은 [로컬 패키지 안내](../local-package.md)를 따릅니다.
manifest 해시 검사 후 인프라 → 사설 ACR 이미지 → 양 앱 → 샘플/복제/읽기 →
Traffic Manager/서비스 smoke까지 완료되어야 성공입니다.

최종 전달 ZIP에는 원본 릴리스 assets와 `source/` 아래 현재 코드·워크숍 문서 스냅샷을
함께 담습니다. 시작 문서는 ZIP 루트의 `DEPLOYMENT.md`입니다.
빌드/배포의 로컬 상태, 계정 암호, kubeconfig, 인증서, 토큰, Git 메타데이터는 포함하지 않습니다.
내부 `deployment-tools.zip`과 이미지/ARM assets는 실증한 원본을 변경하지 않았습니다.

## 이번 검증에서 하지 않은 작업

- Git commit/push, GitHub Release 공개 게시, 미게시 공개 버튼 활성화.
- 실제 Storage/PG/EH failover·failback, 99:1 라우팅 전환, 장애 주입.
- 성능/SLA/RTO/RPO 인증.

Event Hubs Standard Geo-DR는 metadata-only이며 이벤트 payload를 복제하지 않습니다.
fail-forward 후 이전 namespace로 자동 failback하지 않습니다.
